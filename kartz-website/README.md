# Kartz PK website

A single page website for Kartz PK (go karting). One file, no build step: open `index.html` in a browser or drop it on any static host (Vercel, Netlify, GitHub Pages).

## Placeholders to replace before going live

All business details sit in the `KARTZ` object near the bottom of `index.html`:

| Field | Now |
| --- | --- |
| `whatsapp` | `923000000000` (booking form and the WhatsApp button send here) |
| `phoneDisplay` | `+92 300 0000000` |
| `address` | `Venue address, City, Pakistan` |
| `instagram`, `facebook`, `tiktok` | `#` |
| `prices` | Sample PKR prices. Also update the prices shown in the Pricing section and the package dropdown. |

Also check in the HTML: track length and kart count (hero stats), opening hours, age and height limits (FAQ), and the sample leaderboard names in the script.

## What's on the page

Hero, experiences, how it works, pricing, live style leaderboard (sample data), birthdays and corporate events, safety, booking form (builds a WhatsApp message with a price estimate), FAQ and footer. Works on phones.
